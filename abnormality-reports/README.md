# 設備異常報告資料庫

設備工程師用的異常報告紀錄、維修保養分析資料庫。拍照上傳 → Claude 轉錄成標準格式 → 自動建檔、比對重複、累積知識。

## 結構
```
abnormality-reports/
├── TEMPLATE.md          標準異常報告格式
├── database.csv         總表（每份報告一列，可用 Excel 開啟做樞紐分析）
├── equipment.csv        設備主檔
├── reports/YYYY/        每份報告 AR-YYYYMMDD-NN.md
├── photos/AR-.../       原始照片
└── knowledge/patterns.md 學習累積：常見異常、重複異常、速查表、PM 建議
```

## 使用方式
1. 在對話中上傳異常報告照片（紙本、手寫單、設備現場、警報畫面皆可），可補充口述。
2. Claude 辨識內容，依 `TEMPLATE.md` 產生報告，辨識不清處標 `[?]` 並向你確認。
3. 寫入 `database.csv`、更新 `equipment.csv`、`knowledge/patterns.md`。
4. 若與歷史異常重複，會主動提醒並建議 PM 改善。

## 編號規則
`AR-發生日期-當日流水號`，例：`AR-20261006-01`

## 嚴重度
| 等級 | 定義（可依公司規定調整） |
|---|---|
| A | 停機 ≥ 4 小時、安全事件、或客訴等級品質異常 |
| B | 停機 30 分 ~ 4 小時、或批次品質影響 |
| C | 停機 < 30 分、無品質影響 |

## 可做的分析
- 設備別 / 類別 停機柏拉圖、MTBF / MTTR 趨勢
- 重複異常 Top N、4M1E 原因分布
- 維修費用統計、PM 項目有效性檢討
