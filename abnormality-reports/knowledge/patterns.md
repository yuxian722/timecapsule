# 異常知識庫（由報告累積學習）

每新增一份報告後更新本檔。用於：重複異常預警、故障排除參考、PM 改善建議。

## 公司報告格式（從照片學到）
- **修機過久回報**（簡報一頁）：標題「設備 修機過久回報｜異常」，右上「站別 · 樓層 · 日期」。
  - 左：停機時間（X 小時 X 分、起迄、復機狀態）、發現情境「人事時地物」、影響範圍（當站）、立即產品處置、附圖 3 張。
  - 右：原因解析（步驟編號 + 狀態標籤：異常發現 / 無效 / 已完成）、故障流程圖（標示故障點 / 已排除）、改善措施 Short term / Long term（負責人 | 日期 Done、SOP 編號）。
- 人員格式：班別/姓名（輪班、常日）。
- SOP 編號格式：S-XXXX-站別-XXX（例 S-2531-DA-095）。
